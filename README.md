# SmartLocker — Автоматична камера схову 📦
### Веб-інтерфейс та інтерактивний прототип до Лабораторної роботи №1
**Дисципліна:** «Людино-машинна взаємодія» (ЛМВ)  
**Кафедра:** Комп'ютерних наук, Харківський національний університет радіоелектроніки (ХНУРЕ)  
**Тема:** «Побудова та програмна реалізація моделей, що використовуються у процесі розробки інтерфейсів»

---

## 🌟 Про проєкт

Програмний продукт являє собою інтерактивний прототип системи управління **автоматичною камерою схову (Smart Locker)**, розташованою у публічних місцях (парки, вокзали, торговельні центри, туристичні локації м. Харкова).

Інтерфейс розроблено на основі **концептуальної моделі користувача** та **моделі проектувальника інтерфейсу**, сформованих за результатами опитування цільової аудиторії.

---

## 📱 Відповідність звіту та реалізовані екрани

1. **Головний екран (Рисунок 1 у звіті):**
   - Інтерактивна мапа на базі Leaflet.js з географічними мітками камер схову (Сад Шевченка, ТРЦ «Нікольський», Південний вокзал, Саржин Яр).
   - Відображення відстані до користувача, робочого графіка та кількості вільних комірок.
   - Швидкі фільтри за категоріями (Парки, Вокзали, ТРЦ) та пошуковий рядок.

2. **Вибір комірки та підтвердження (Рисунок 2 у звіті):**
   - Вибір розміру комірки:
     - **S** (Мала, 30×40×50 см, 25 грн/год) — пакети з покупками, рюкзак, ноутбук;
     - **M** (Середня, 45×60×60 см, 45 грн/год) — середня валіза, дорожня сумка;
     - **L** (Велика, 60×80×80 см, 70 грн/год) — габаритний багаж, спорядження.
   - Інтерактивна шафа/матриця комірок зі світлодіодною індикацією стану: *вільна* (зелений), *обрана* (синій/акцент), *зайнята* (приглушений сірий, блокування натискання).
   - Попередній розрахунок вартості за повзунком годин (гарантія відсутності прихованих платежів).
   - Модальне вікно підтвердження та вибору способу оплати (Apple Pay / GPay / Картка).

3. **Екран «Моя оренда» (Рисунок 3 у звіті):**
   - **Метафора «номерка» (квитанції):** точна адреса шафи, номер комірки та її габарити.
   - **Живий динамічний таймер:** секундомір тривалості оренди з похвилинним підрахунком вартості.
   - **Резервний доступ:** генерація 6-значного PIN-коду та оптичного QR-коду на випадок розрядженого смартфона.
   - Індикатор стану замка («Дверцята зачинені та заблоковані»).

4. **Відкриття комірки однією кнопкою (Рисунок 4 у звіті):**
   - **Метафора «ключа від шафки»:** велика помітна акцентна кнопка «ВІДКРИТИ КОМІРКУ».
   - Звуковий відгук спрацьовування електромагнітного замка (синтезований за допомогою Web Audio API).
   - Спливаюче повідомлення про успішне відчинення комірки з інструкцією забрати речі.
   - Кнопка завершення оренди із збереженням чека до історії.

5. **Напрями подальшого розвитку (Таблиця 2 у звіті):**
   - Повноцінний екран **«Історія оренд»** із статистикою тривалості та витрат.
   - Інтегроване вікно **«Звіт до лаби»** з повним текстом звіту, таблицями опитування, сторібордом та теоретичним обґрунтуванням.
   - Перемикання режимів відображення: ергономічний смартфонний фрейм та розширений вигляд.

## 🛠 Технологічний стек

- **HTML5:** Семантична розмітка, нативні теги `<dialog>`, доступність (ARIA).
- **CSS3:** Custom Properties (змінні дизайну), адаптивна Flexbox/Grid верстка, висока контрастність для вулиці, ергономічні touch-target елементи (≥ 48–64px).
- **JavaScript (ES6+):** Vanilla JS без зайвих залежностей, стан у `localStorage`, Web Audio API для звуку замка, асинхронні події.
- **Leaflet.js & OpenStreetMap / CartoDB:** Інтерактивна картографія.
- **Font Awesome 6:** Сучасна векторна іконографія.
