# SmartLocker — Автоматична камера схову 📦

Сучасний, чистий та адаптивний веб-сервіс для автоматичних камер схову у публічних місцях міста (парки, вокзали, торговельні центри).

## 🌟 Основні можливості

- **Інтерактивна карта та пошук:** швидкий пошук найближчого вільного локера з відстанню та наявністю місць на інтерактивній карті Leaflet.
- **Миттєвий вибір комірки з прозорою ціною:** вибір потрібної комірки (S / M / L) безпосередньо у шафі із зазначенням точної погодинної вартості.
- **Швидкий розрахунок вартості:** зручний повзунок часу оренди без прихованих платежів.
- **Екран «Моя оренда»:** живий секундомір тривалості оренди, автоматичний підрахунок вартості та велика кнопка віддаленого відмикання комірки зі звуковим відгуком замка.
- **Резервний доступ:** оптичний QR-код та 6-значний PIN-код для відкриття на фізичній клавіатурі локера.
- **Історія оренд:** збереження попередніх завершених квитанцій.

## 🛠 Технології

- **HTML5 & CSS3:** Сучасний мінімалістичний дизайн, повна адаптивність під мобільні пристрої та комп'ютери.
- **JavaScript:** Клієнтська логіка без важких фреймворків, Web Audio API, `localStorage`.
- **Leaflet.js:** Швидкі та надійні інтерактивні карти на базі OpenStreetMap / CartoDB.
